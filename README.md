# AI Trading Research System

A modular research repository for analyzing financial-market data, testing systematic trading ideas, and evaluating strategies across changing market conditions.

## Project Areas

### NQ Trading Research
- Topstep-focused trading system
- Feature engineering and labeling
- Walk-forward testing
- Risk and execution analysis
- Model checkpoints and performance evaluation

### Gold Trading Research
- Gold trading agent
- Strategy testing and optimization
- Historical GC market data
- Cross-market analysis

### TradingView Pine Scripts
- Market structure tools
- Bias and displacement indicators
- SMT divergence analysis
- Trading-session utilities
